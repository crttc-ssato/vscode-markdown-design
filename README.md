# Markdown Design

Markdown専用の編集・プレビュー画面を提供するVS Code拡張機能です。本文の上に固定したツールバーを表示し、同じ画面で編集と閲覧を切り替えられます。

## 使い方

1. Markdownを含むフォルダーをVS Codeで開きます。
2. 左端の **Markdown Design** アイコンをクリックします。
3. Markdownエクスプローラーでファイルを選択します。
4. 上部の鉛筆ボタン **編集する / プレビュー** で表示を切り替えます。

コマンド **Markdown Design: 専用画面を開く** からも利用できます。

### 専用ツールバー

編集時は次の順番で表示します。各アイコンにカーソルを合わせると操作名が表示されます。

保存 → Undo → Redo → 見出し → 太字 → 斜体 → 下線 → 取り消し線 → インラインコード → 箇条書き → 番号付きリスト → 引用 → 水平線 → リンク → 画像 → テーブル → コードスニペット。編集／プレビュー切り替えは右端にあります。

- **保存アイコン**: Ctrl+S（macOSはCmd+S）でも保存できます。
- **見出し**: ホバーまたはクリックでレベル1〜7を選択します。キーボードではTabでフォーカスし、上下矢印・Enterで選択、Escapeで閉じます。カーソル行または選択行の見出しレベルを変更します。
- **太字・斜体・下線・取り消し線・インラインコード**: 選択テキストを対応する記法で囲みます。未選択の場合は入力用のテキストを挿入します。
- **リスト・引用**: カーソル行または選択した複数行に記法を付けます。番号付きリストは1から連番にします。
- **水平線**: カーソル位置、または選択範囲の末尾へ挿入します。選択テキストは残します。
- **リンク**: 選択テキストをリンク名にし、URLを入力できます。
- **画像**: ファイル選択またはURL入力で追加します。文書のフォルダー内の画像は相対パスで参照し、外部の画像は文書横の `assets` にコピーします。元画像は変更しません。画像コピーの削除はUndo対象外です。
- **テーブル・コード**: Tabで各入力欄を順に移動できます。コードブロックは選択テキストを本文に使用します。
- **Undo / Redo**: VS Codeの文書履歴を利用します。Ctrl+Z / Ctrl+Shift+Zにも対応します。

Markdown標準の見出しはレベル6までです。**レベル7は `####### 見出し` という専用画面の拡張記法**で、ほかのMarkdownビューアでは通常の文章として表示される場合があります。下線はHTMLの `<u>…</u>` を使用します。

編集画面はCodeMirrorを利用し、行番号、Markdown・コードの色分け、インデント、選択範囲の操作、検索を提供します。Ctrl+Fで編集画面の検索パネルを開きます。

### 専用プレビュー

- ライト・ダークテーマに対応したドキュメント表示
- 中央の長い検索欄に虫眼鏡と前後移動ボタンをまとめて表示。Enter / Shift+Enterで次／前へ移動し、Escapeで解除
- タスクは「完了数/総数件のタスクが完了」と表示し、すべて完了しても件数を保持。チェック操作は元のMarkdownの `[ ]` / `[x]` に反映
- **目次**にホバーまたはクリックすると、見出しを階層表示。クリックで見出しへスクロールします。キーボードの上下矢印・Enterでも操作できます。見出しがない場合はその旨を表示
- ツールバーの保存状態表示は省略。保存ボタンとVS Codeの通常の未保存表示は利用できます
- 表、引用、折りたたみ、見出しリンク、言語名付きコードブロックの色分け

チェック変更や編集内容はまずVS Codeの文書に反映されます。保存は通常の保存・自動保存設定に従います。未保存の編集やカーソル位置は、画面内のモード切り替えで維持します。

### 外部編集との同期

VS CodeのTextDocumentを文書の基準とし、編集画面とのメッセージ通信にはバージョンと応答IDを付けます。連続入力は順番に反映します。

未反映の入力と外部の更新が競合した場合、入力中の内容を保持して案内します。**最新の文書を読み込む**（入力中の内容を破棄）か、**入力中の内容を反映**（最新文書を入力内容で置換）を選択できます。書き込みに失敗した場合も入力内容を保持します。

### ファイル一覧

Markdownを含むフォルダーのみ階層表示します。複数フォルダーのワークスペースに対応し、追加・削除・名前変更に追従します。`node_modules`、`.git`、`.cache` は対象外です。

一覧のソースボタンからVS Code標準エディターを開くこともできます。専用編集画面はVS Code標準エディターの拡張・補完・設定をそのまま継承するものではありません。

## 設計

編集・プレビュー・文書同期を分離し、将来別の編集UIを追加しやすい構成にしています。現時点ではMarkdownテキスト編集であり、WYSIWYG編集は未実装です。

| 部品 | 役割 |
| --- | --- |
| `src/extension.js` | VS Codeの文書、保存、Undo、メッセージ処理 |
| `src/shell.js` | 共通ツールバーと専用画面の枠組み |
| `webview/editor.js` | CodeMirror編集エンジンと構文挿入 |
| `webview/preview.js` / `preview-search.js` | プレビュー操作・本文検索 |
| `webview/session.js` | 入力の同期、応答待ち、競合時の保持 |
| `webview/workbench.js` | 画面内モード切り替えと各部品の接続 |
| `src/markdown.js` | Markdown描画、構文色分け、HTMLサニタイズ |
| `src/explorer.js` | Markdownエクスプローラー |

プレビューにはmarkdown-it / highlight.js / sanitize-htmlを使用します。スクリプトやイベント属性は実行しません。編集エンジンは拡張に同梱し、CDNや外部サービスへ文書を送信しません。Markdownで参照されたHTTPS画像はその配信元から読み込みます。

他のMarkdown拡張の描画機能、Mermaid、VS Codeの構文配色との完全一致は含まれません。標準プレビュー（Ctrl+Shift+V）には共通スタイルのみ適用します。

## 開発・検証

Node.js 22以上、npm、VS Code 1.100.0以上を使用します。

```sh
npm ci
npm run build
npm test
```

F5で拡張開発ホストを起動します。起動前にビルドを実行します。`examples/preview.md` を専用画面で開いて確認してください。ソース変更後は再ビルドし、開発ホストを再読み込みしてください。

ブラウザー向けコードは `dist/workbench.js` にバンドルされます。利用時にはビルド環境もネットワーク経由のライブラリ取得も不要です。`dist/THIRD_PARTY_LICENSES.txt` に同梱ライブラリのライセンスを出力します。

## 配布

```sh
npm run package
code --install-extension vscode-markdown-design-0.3.0.vsix
```

パッケージ作成時にはビルドが実行されます。**Install from VSIX...** からもインストールできます。Marketplaceへの公開は行いません。
